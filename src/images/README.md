# Test Images Directory

Place your test images here for the VL-JEPA pipeline.

## Supported Formats
- `.jpg` / `.jpeg`
- `.png`

## Usage

When running `python main.py --interactive`, you'll be able to select images from this directory.

## Example Images

You can download sample images from:
- [Unsplash](https://unsplash.com/) (free stock photos)
- [COCO Dataset samples](http://cocodataset.org/)
- Your own photos

### Recommended Test Images:
1. Animals (cats, dogs, birds)
2. Outdoor scenes (beaches, mountains, cities)
3. Indoor scenes (rooms, offices)
4. People in various activities

The images will be automatically resized to 224x224 pixels for the Vision Transformer.
